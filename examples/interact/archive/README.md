# Archived interaction experiments

These files are retained to reproduce earlier calibration and scripted-user
experiments. They are tested for import and internal consistency, but they are
not the supported CookSim launch path. New work should use
[`../cooking_gemini/`](../cooking_gemini/) and the current
[`../docs/COOKING_GEMINI_HANDOFF.md`](../docs/COOKING_GEMINI_HANDOFF.md).
